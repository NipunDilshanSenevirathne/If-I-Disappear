If I Disappear: security and privacy, layer by layer

Everything from the internet is untrusted, and so is everything a model says. Secrets are removed before anything is stored or sent, every model answer is checked by code, and only facts a person accepted can change what the family sees.

Untrusted: the internet

What people sendvoice notes, photos, PDFs, typed notes. Any of them may contain text written to steer a model.
A handover linkthe token sits in the URL fragment (#), so browsers never send it to the server's logs or to other sites
Browsersthe person leaving, the person staying, visitors

The edge of the serviceevery request

Upload checksfile type and size (15 MB) · at most 40 sources per household · consent ticked before anything goes to Gemini
Who is callingsigned visitor session (HMAC-SHA256, 30 days) · the owner checked on every request · rate limits per visitor and per address
HTTPS onlystrict Content-Security-Policy: scripts from the app itself only · no framing by other sites · no third-party trackers

Trusted core: the AI reads, code decides

1Remove secretsPINs, passwords, card and account numbers, before storing or sending; phone numbers cut to the last 4 digits
2Fence the sourcesource text is wrapped as data, <<<SOURCE … SOURCE>>>, never as instructions
3Gemini or Gemmareads and returns typed JSON. Its answer is treated as untrusted too.
4Check every answerschema validation · each quote found word for word in its source · citations must belong to the finding
5Review gatea model can only propose; a fact counts once a person accepts it
6Deterministic engineevery state, date, count, plan and grade a person sees

Private storageonly the service's own account can read or write it

Cloud Storagethe uploaded files · no public access · deleted after 30 days
Secret Managerthe Gemini key and the session key · never sent to a browser
Cloud Loggingno keys, no tokens, no note text in the logs
Share linksonly a SHA-256 fingerprint of each token is kept · switch a link off any time
Firestoreone document per household · security rules deny every browser
a guard a model (untrusted output) deterministic code private storage the key, used on the server only
Tested as if the model were hijacked: the evaluation feeds hostile model output straight into this code, and 19 of 19 containment checks hold; 16 of 16 test secrets are removed. Live, a note with hidden instructions produced 0 facts and changed nothing.
